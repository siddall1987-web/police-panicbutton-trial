# Police Panic Button (Trial Version)

This is the **trial version** of the Police Panic Button resource for QBCore.  
It allows server owners to test the core functionality before upgrading to the full version.

---

## 🚨 Trial Limitations
This trial version includes reduced functionality:

- Blip duration limited to **20 seconds**
- Panic button cooldown of **45 seconds**
- Trial notifications displayed on activation
- Console message indicating trial version
- No configuration options for cooldown or duration

## 🎮 Usage
Players with the **police job** can activate the panic button using:

- Command:/panic


Or bind it to a key using your preferred keybind system.

When activated:
- All police receive a notification  
- A dispatch alert is sent  
- A blip appears for 20 seconds  
- A sound plays
